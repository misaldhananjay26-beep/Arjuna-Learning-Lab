# Arjuna Learning Lab

A small interactive prototype for visual, project-based learning for young innovators.

## Focus

This prototype explores age-banded lessons, character-guided explanations, constructive retry, and visible learning progress without open-ended child social features.

## Included

- Explorer, Builder, and Inventor level bands
- Visual lesson cards for AI, robotics, and social impact
- Interactive AI vision concept quest
- Constructive feedback for right and wrong answers
- Responsive, dependency-free frontend

Open `index.html` in a browser or serve the folder with any static server.

## Direction

Future work should keep curriculum, progression, and assessment deterministic while using AI only for bounded explanations, hints, and reviewed question variants.
